# AIWorkHub Architecture Decision Records

Architecture Decision Records (ADRs) explain the durable product choices that
shape AIWorkHub's authority, security and interoperability contracts.

| ADR | Decision | Status |
| --- | --- | --- |
| [0001](0001-repository-native-authority.md) | Repository-native authority and local stdio transport | Accepted |

New ADRs use four sections: context, decision, consequences and validation.
Accepted records are immutable historical decisions; a later decision that
changes one is added as a new ADR and links back to the superseded record.
