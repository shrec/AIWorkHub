# AIWorkHub Support

## Getting help

Start with the [Getting Started guide](docs/GETTING_STARTED.md) and the
[Architecture overview](docs/ARCHITECTURE.md). The dashboard's **Logs** view
shows the latest repository-scoped runtime events and is the best first place
to diagnose connection, routing or worker-launch failures.

For reproducible product bugs, open a
[GitHub issue](https://github.com/shrec/AIWorkHub/issues/new/choose) with:

- AIWorkHub extension and MCP runtime versions;
- operating system and VS Code version;
- local, WSL or Remote-SSH environment;
- repository initialization state;
- exact visible status and bounded relevant logs;
- minimal steps to reproduce.

Never attach credentials, provider tokens, private source, prompts or memory
content. Redact hostnames and paths when they are not relevant.

## Feature requests

Open a feature request and describe the user outcome, repository workflow and
evidence that would prove the feature works. See the
[Product Roadmap](docs/PRODUCT_ROADMAP.md) before proposing a large new area.

## Security reports

Do not report vulnerabilities in a public issue. Follow
[SECURITY.md](SECURITY.md) instead.
